* Project Genesis & Philosophy

TriviaNetDMR was born out of real-world frustration running amateur radio trivia
nets over DMR repeaters. Existing paper logs, spreadsheets, and general logbooks
were too clunky:
- Entering a callsign during check-ins broke conversational flow while searching QRZ.
- Managing who answered first across multiple rounds on paper was chaotic.
- Manually calculating check-in points, trivia points, and bonus points was error-prone.

The solution was to build a purpose-engineered terminal dashboard in Rust with
sub-millisecond responsiveness, asynchronous callbook intelligence, and automated
contest management.

* Solved Engineering Hurdles & Bug Logs

** Issue 1: Terminal Raw Mode Residuals on Abnormal Exit
- *Problem:* Crashing or terminating without resetting Crossterm raw mode left the user's
  terminal session scrambled, hiding the cursor and disabling echo.
- *Solution:* Added a panic hook and structured exit path in =src/main.rs= ensuring
  =disable_raw_mode()=, =LeaveAlternateScreen=, and =terminal.show_cursor()= are always invoked.

** Issue 2: Headless SSH Agent Key Refusal in Subshells
- *Problem:* Background push operations through Git-Flow failed with
  =agent refused operation= due to 1Password desktop agent requiring GUI biometric confirmation.
- *Solution:* Implemented an isolated =SSH_ASKPASS= wrapper communicating with =id_rsa=
  under explicit user instruction, followed by immediate zeroization of credentials from disk.

** Issue 3: Table Cell Type Homogeneity in Ratatui
- *Problem:* When creating the Topic Picker table, mixing =Line= and =Span= types within
  a single =Row= produced compiler error =E0277= regarding =From<Line> for Span=.
- *Solution:* Standardized all table cells to uniform =Span= instances, using pre-formatted
  composite strings for the status and active badge columns.

** Issue 4: First-Run Cloned Repository Session Pollution
- *Problem:* Running the application directly after a clean clone loaded previous developer test
  participants and round 8 because =trivia_log.json= had been committed with stale state.
- *Solution:* Reset =trivia_log.json= to an empty initial state template, added Serde defaults to
  =AppStateDump= with =default_round_number() = 1=, and made =load_from_file= treat empty 0-byte files
  as clean starts.
