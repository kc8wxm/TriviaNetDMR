* Welcome to the TriviaNetDMR Commonplace Book

Welcome to the central knowledge repository, engineering journal, and operator's
companion for *TriviaNetDMR*. This commonplace book captures design decisions,
system architectures, Net Control Station (NCS) operating procedures, historical
logs, and future ideas for running amateur radio trivia nets.

** Mission Statement
Amateur radio trivia nets bring operators together across DMR talkgroups and
analog repeaters for technical camaraderie, knowledge sharing, and friendly
competition. Traditional net logging using paper or general-purpose loggers
creates immense cognitive load for the Net Control Station (NCS):
- Manual callbook lookups slow down the net.
- Fixed turn orders disadvantage operators who answer late in the queue.
- Scoring arithmetic distracts from managing the airwaves and repeater timeouts.

*TriviaNetDMR* was engineered in Rust to eliminate this friction entirely.
It delivers a distraction-free, keyboard-driven Terminal User Interface (TUI)
with automated QRZ.com lookups, automatic fair queue rotation, markdown question
prompters, and instant contest exports.

** At a Glance: Master Keyboard Shortcut Matrix

The entire application is controlled via intuitive single-key shortcuts:

| Key | Category | Action | Operational Impact |
|---+---+---+---|
| =c= | Roster | Check-in Operator | Opens modal to enter callsign; triggers async QRZ lookup |
| =e= | Roster | Edit Callsign | Modifies active callsign with duplicate check and re-queries QRZ |
| =d= | Roster | Delete Operator | Removes operator from session and queue with confirmation |
| =n= / =Enter= / =↓= | Queue | Next Turn | Advances active turn indicator to the next operator in queue |
| =p= / =↑= | Queue | Previous Turn | Rewinds active turn indicator for score corrections |
| =r= | Queue | Rotate Round | Finishes round, increments round number, shifts queue, advances question |
| =y= | Scoring | Award Trivia (+1 pt) | Adds 1 point to active operator's trivia score |
| =x= | Scoring | Deduct Trivia (-1 pt) | Deducts 1 point from active operator's trivia score |
| =b= | Scoring | Award Bonus (+1 pt) | Adds 1 point to active operator's bonus score |
| =v= | Scoring | Deduct Bonus (-1 pt) | Deducts 1 point from active operator's bonus score |
| =a= | Trivia | Toggle Answer Visibility | Reveals/hides canonical answer and Net Control background fact |
| =[= / =←= | Trivia | Previous Question | Manually navigates back to previous question in deck |
| =]= / =→= | Trivia | Next Question | Manually advances to next question in deck |
| =t= | Trivia | Browse & Switch Decks | Opens modal scanner listing all =Topic/*.md= decks with validation status |
| =u= | Trivia | Hot-Reload Deck | Re-reads active Markdown deck from disk without losing net scores |
| =f= | Contest | Final Scoreboard | Interactive leaderboard modal with podium ranks (🥇, 🥈, 🥉) and scrolling |
| =s= | Contest | Export Contest | Generates RFC 4180 CSV spreadsheet or structured JSON results |
| =Backspace= / =k= | Session | Clear Session Log | Resets active roster, queue, and scores with confirmation prompt |
| =?= / =h= / =F1= | System | Help Menu | Pops up interactive keyboard shortcut and command reference modal |
| =q= / =Esc= | System | Quit / Close | Exits active modal, or shuts down TUI and prints final scores |

** Quick Start Commands

#+BEGIN_SRC bash
  # Compile and launch the release dashboard
  cargo run --release

  # Run the full automated test suite (26 unit tests)
  cargo test

  # Pre-flight validate all question decks before a net
  cargo run -- --check Topic/

  # Launch with a specific question deck
  cargo run --release -- Topic/Questions-2.md
#+END_SRC

** Environment & Toolchain

- *Language:* Rust (2024 Edition)
- *TUI Framework:* [[https://github.com/ratatui-org/ratatui][Ratatui v0.30.2]] on [[https://github.com/crossterm-rs/crossterm][Crossterm v0.29.0]]
